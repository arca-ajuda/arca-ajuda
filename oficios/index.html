❓ Como usar a app de Ofícios

1. Criar um ofício — carrega em + Novo Ofício, escolhe o tipo (o texto do modelo é preenchido), completa o que está entre [parênteses retos], escolhe o assinante e guarda. O número é atribuído automaticamente (001/2026, 002/2026…).

2. Imprimir / PDF — na lista, botão 🖨. Abre o ofício em papel timbrado numa nova janela; usa "Imprimir" e escolhe "Guardar como PDF" para enviar por email.

3. Estado — um ofício nasce como Rascunho; quando o enviares, muda para Enviado (podes fazê-lo na lista com ✅).

4. Modelos — em Modelos podes alterar os textos base de cada tipo. Ficam guardados na cloud para todos os dispositivos.

5. Dados do timbrado — nome, NIF, morada, email e site vêm da app de Sócios (Configurações → Associação). O logótipo é partilhado no mesmo dispositivo.

6. Protocolos — em Protocolos registas acordos com entidades (colaboração, patrocínio, cedência de espaço…): identificas as duas partes, o objeto, a vigência e as cláusulas. A impressão sai em formato de protocolo, com assinatura das duas partes, e a numeração é própria (P-001/2026).

7. Duplicar — botão ⧉ na lista cria um novo ofício com o mesmo texto (útil para enviar o mesmo pedido a várias entidades).
